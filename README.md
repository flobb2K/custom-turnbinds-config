# flobb's turnbinds
# Turnbinds с настраиваемой скоростью поворота для CS2/CSGO

Этот конфиг с помощью обходного решения добавляет устаревшие консольные переменные `cl_yawspeed` и `cl_pitchspeed` из ***Counter-Strike: Source*** в новейшую игру серии, ***Counter-Strike 2***, а также в её предшественницу, ***Counter-Strike: Global Offensive***, <ins>используя только консольные команды</ins>. Кроме того, он добавляет множество различных <ins>биндов и настроек</ins>, которые позволяют в полной мере использовать эти давно утраченные, но не забытые консольные команды.

## Возможности
### cl_yawspeed
Этот конфиг позволяет **изменять yawspeed**, вводя `cl_yawspeed_[value]` в консоль разработчика или выполняя `.cfg`-файлы.
>[!IMPORTANT]
>`cl_yawspeed` измеряется в **градусах в секунду** и может быть любым целым числом от `1` до `300`.

### cl_pitchspeed
Этот конфиг позволяет **изменять pitchspeed**, вводя `cl_pitchspeed_[value]` в консоль разработчика или выполняя `.cfg`-файлы.
>[!IMPORTANT]
>`cl_pitchspeed` измеряется в **градусах в секунду** и может быть любым целым числом от `1` до `45`.

### Fixed-бинды
**Привязывайте** к **клавишам** столько **разных** команд `cl_yawspeed`/`cl_pitchspeed`, сколько захотите!  

`bind "[key]" "cl_yawspeed_[value]"`  
`bind "[key]" "cl_pitchspeed_[value]"`

### Toggle/Cycle-бинды
- **Переключайтесь между** двумя, тремя или четырьмя **разными** значениями `cl_yawspeed` с помощью **одной клавиши**!
- **Переключайтесь между** двумя или тремя **разными** значениями `cl_pitchspeed` с помощью **одной клавиши**!
- **Сочетайте** Fixed-бинды с Toggle/Cycle-биндами, чтобы Fixed-бинды **тоже влияли на** alias цикла!
- По желанию **автоматически сбрасывайте** alias цикла `cl_yawspeed` **при каждом сбросе** этапа или забега!

### Hold-to-Activate-бинды
Hold-to-Activate-бинды **нужно удерживать**, чтобы изменить значение `cl_yawspeed`.  
**Пока ни один из этих биндов не удерживается**, действует настраиваемое значение `cl_yawspeed` по умолчанию.  
Конфиг поддерживает до трёх Hold-to-Activate-биндов, которые вместе со значением по умолчанию дают до четырёх разных скоростей.  

>[!IMPORTANT]
>Hold-to-Activate-бинды **нельзя сочетать** с Fixed-биндами или Toggle/Cycle-биндами!

### Визуальная обратная связь
- Смена цвета **HUD**
- Смена цвета **прицела**
- Смена цвета **и HUD, и прицела** одновременно
- 10 разных цветов для всего перечисленного выше

>[!NOTE]
>Чтобы **смена цвета прицела** работала в ***Counter-Strike: Global Offensive***, нужно **отредактировать файл** `turnbinds\setup\setup.cfg`.   
>Дальнейшие инструкции см. в этом файле.

### Звуковые эффекты
- Добавляйте **звуковые эффекты** к своим биндам!
- Выбирайте из **21 разного** звука!

>[!NOTE]
>**Любой** звуковой файл из игровых файлов CS2/CS:GO, включая музыкальные наборы, **можно добавить** как звуковой эффект **с помощью файла** `turnbinds\setup\setup.cfg`.
>Подробности см. в этом файле.

### Полная читаемость
**Никаких секретов**. В каждом конфиг-файле есть собственный заголовок с описанием его назначения, и я постарался сделать так, чтобы всё было **легко читать и понимать**.

### Полная настраиваемость
В файле `turnbinds\settings.cfg` я предусмотрел **множество настроек**, чтобы вы могли сделать этот конфиг **по-настоящему своим**. 
Если вы уже экспериментировали с конфигами Counter-Strike и хотите сами добавить новые функции, рекомендую также заглянуть в файл `turnbinds\setup\setup.cfg`.

## Как использовать
1. Скачайте `.zip`-файл с конфиг-файлами в разделе «Releases».
2. Распакуйте все файлы из `.zip`-архива.
3. Выберите предпочитаемый язык конфиг-файлов и откройте соответствующую папку.
4. Внутри вы найдёте папку `turnbinds`. Скопируйте эту папку вместе со всем содержимым в  
   `[Диск]:\Program Files (x86)\Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg`
5. Настройте конфиг с помощью файла `settings.cfg` в папке `turnbinds`.
6. Чтобы выполнить конфиг, введите `exec turnbinds\exec.cfg` в консоль разработчика. На скриншоте показано, как это должно выглядеть после выполнения.
7. Для удобства рекомендую привязать команду exec к клавише: `bind "[key]" "exec turnbinds\exec.cfg"`
8. Также можно добавить `exec turnbinds\exec.cfg` в файл `autoexec.cfg`.

## Зачем использовать этот конфиг вместо внешних программ для turnbinds?
### Преимущества
- Гораздо больше возможностей для создания биндов
- Визуальная обратная связь
- Звуковые эффекты
- Используются только консольные команды
- Возможность менять настройки прямо в игре через консоль разработчика

### Недостаток
Поскольку `cl_yawspeed` и `cl_pitchspeed` на самом деле не существуют в игре как convar-переменные, конфиг «эмулирует» их, изменяя команды `turnleft`/`turnright` и `turnup`/`turndown`. Из-за этого нельзя изменить скорость поворота, пока вы поворачиваетесь. Чтобы изменение скорости вступило в силу, нужно ненадолго прекратить поворот, а затем начать его снова.
